## 二、本轮闭合的五处

| # | 问题 | 改动位置 | 改法 | 为什么可判定 |
| --- | --- | --- | --- | --- |
| 1 | `//map` 标记符未定义，`p'a"b` 无法切分 | §二 符号总表、§3.2、§4.17 | 新增“映射标记符”行；`//map{}` 行内按 `短词 + 第一个非短词字符（标记符）+ 行尾（长词）` 切分，标记符为 `'` / `` ` `` / `<`，只占一个字符，长词到行尾 | 短词字符集先吃掉 `p`，第一个非短词字符即标记符，其余到行尾是长词；`p'a"b` 唯一读作 `p` + `'` + `a"b` |
| 2 | “回读为同一 value”不等于 AST 等价 | §4.17 | 值类映射统一归约为 `STRING` 节点，不产生 `LongWord` 节点；判据改为“忽略 span 后节点类型与 value 逐一相等” | 节点类型固定为 `STRING`，比较是结构相等，不再依赖“同一 value”的模糊说法 |
| 3 | `call_stmt` 的 `arg` 无产生式 | §三 | 补 `arg := value`，`value := STRING \| NUMBER \| 裸词 \| $变量 \| .字段`（0.1.1 起含裸词） | 每个实参只能是五种 value 之一，调用参数可逐项归约 |
| 4 | `verb_call` 删主语导致条件位无法归约 | §三、§4.1 | `verb_call := [subject] <动词> ...`，`subject := role \| 裸词 \| 引号 \| $变量`；§4.1 明确四种主语形态 | `if $cfg <contains> debug=true` 中 `$cfg` 落主语槽，条件可归约为 `verb_call` |
| 5 | `//map {` 带空格是否仍算区块头未定 | §3.1、§七.1、§4.19 | 规定 `//` 后跳过零个或多个空格，读 `map`/`fn`，再跳过零个或多个空格，下一字符是 `{` 即区块头；否则整行注释 | 规则按字符序列执行，`//map{`、`//map {`、`// map{`、`//fn {` 结果唯一 |

## 三、A2 裁定后：裸词在 value 位合法

A2 已裁定：`value := STRING | NUMBER | 裸词 | $变量 | .字段`，裸词按 `STRING` 处理。下列示例保留原样，不再改引号：

| 位置 | 片段 | 现读法 | 处理 |
| --- | --- | --- | --- |
| §六 示例 5 | `each $f [in] xs` | `xs` 按字符串，单元素数组，执行一次 | 保留原样；`W-01` 提示 |
| §4.15 说明 | `break done` | `done` 按字符串 | 保留 |
| §4.18 调用 | `@ "name" bare` | `bare` 按字符串 | 保留 |
| §4.13 判据 | `each $f [in] <search> *.yml` | `[in]` 后是 `verb_call`，不受影响 | 不改 |

未改动：`<read> a.yml` 的 `a.yml` 在宾语槽，不是 value 位，保持裸词；`if $cfg <contains> debug=true` 的 `debug=true` 在宾语槽，保持裸词。
