# RILL v1.2 未闭合与争议短清单

> 只列三类：追账未闭合（11 部分 + 1 未动）、两席结论不一致、反证席新提且我认可或无法反驳。已闭合与两席共识不列。

## 一、产生式与结构（§三）

- **I-07** 状语一格里多个并列项，参数个数无法确定 · 卡在 §4.4「一个状语一个参数，多参数用多个状语表示」与同节示例 `(utf-8,backup:daily,timeout:30)` · 两席一致。
- **R-01** 多个介宾短语推不出来 · 卡在 §三 `[[介宾]介宾宾语]` 只一组，而 §4.13、示例 9 写 `[with] prod … [in] $file` · 一致（反证新提，认可）。
- **R-02** `parallel … |> …` 无产生式 · 卡在 §三 `parallel_body := block trailing_block*` 无 `|>`，示例 4 却接 `|>` · 一致。
- **R-03** 独立 `[into]` / `[ok]` 不是 statement · 卡在 §三 `statement` 无 `into_stmt`/`ok_stmt`，§4.9/§4.10 却定义独立形式 · 一致。
- **I-04 / R-04 / R-24** 条件、表达式、主语槽都未定 · 卡在 §三 `condition := simple_stmt_or_pipeline_with_trailing_blocks`、`expr` 全文无定义，且 §4.12 `if$cfg<contains>` 的 `$cfg` 不在 §二 主语（裸词/引号） · 一致。
- **I-29 / R-05** 语法接受重复 `[ok]` / `[error]` · 卡在 §三 `trailing_block*` 与各分支注释 `// 0..1` · 不一致（我判已闭合，反证席判不够清晰）。

## 二、尾随块、段输出与错误

- **I-08** `[into]` 的 lookahead 吃掉 §4.5 的普通介词 · 卡在 §4.9「`]` 后不是 `{` → 独立形式」而独立形式宾语不能是裸词，§4.5 却写 `<merge> feature [into] main` · 一致。
- **I-09** `[ok]` / `[error]` 仍列在 §4.5 常用介词 · 卡在 §4.10 独立形式宾语须 `$变量`，`<send> "x" [ok] user` 无处归约 · 一致。
- **I-14 / R-26** `[into]` 失败是否走用户 `[error]` · 卡在 §4.10「用户写 [error] 覆盖默认实现」vs §4.11「[into] 失败：默认 break」 · 一致。
- **R-06 / C-10** `[ok]` 按 truthy 还是按成功触发 · 卡在 §4.10「判断『结果为真』时进入块」vs §4.11「成功且有 [ok]」 · 一致。
- **I-24 / R-07** `$` 在 `[ok]` / `[error]` 内被内层介词重绑 · 卡在 §4.8「`$` 是最近介词宾语」与同节表「[ok] → 段成功结果」 · 一致。
- **I-38 / R-08** 无介宾语句的段输出没有 `$` 可指 · 卡在 §4.11「语句结果（`$` 当前值）」+ §4.8「`$` 是最近介词宾语」 · 一致。

## 三、`each` / `parallel` 与 `$`

- **I-19 / C-11** `each` 每轮是否新作用域未定 · 卡在 §4.7「外层已存在则覆盖，不存在则建局部」+ §4.13 未写块实例 · 一致。
- **R-10** `each` 头表达式尾随块与 body 两个连块无法切分 · 卡在 §三 `prep_phrase := "[in]" expr` + `each_body := block` · 一致。
- **R-11** 示例 5 `each $f [in] xs` 的 `xs` 是裸词不是变量 · 卡在 §4.8「`$name` 是变量」+ §4.13「[in] 带宾语」 · 一致。
- **R-09** `each` 隐藏 do 的 `[ok]` / `[error]` 里 `$` 无定义 · 卡在 §4.8 表只有「each 循环体 → 当前迭代项」 · 一致。
- **R-12** `parallel` 分支内 `$` = 最终结果数组，执行中成环 · 卡在 §4.8 表「parallel 块内 → 按源序的结果数组」 · 一致。
- **I-18 / R-13** 多分支同时失败取哪个；内层 `[error]` 处理过是否还算失败 · 卡在 §4.14「任一分支失败则整体失败，`$` 是失败分支的错误信息」 · 一致。

## 四、`@` 函数

- **I-49 / R-14** `@` 调用无产生式且与定义同形 · 卡在 §三 只有 `fn_def := "@" fn_template block` · 一致。
- **R-15** `fn_template` 不含尾随块，示例 7 出现两个块 · 卡在 §三 `fn_template` 无 `trailing_block*`，§4.18 示例先写 `[into]{}` 再写函数体 · 一致。
- **R-16** 返回值「最后一条语句结果（或 `$` 最终值）」是二选一 · 卡在 §4.18 该句 · 一致。
- **R-17** 签名只匹配动词+状语+介词，主语/宾语槽位未定 · 卡在 §4.18「实参按位置绑定」+ §三 `fn_template` · 一致。

## 五、`//map` 与展示态

- **I-32 / C-7** 含空格长词展开后的 token 边界与去空白可逆冲突 · 卡在 §4.17「长词可含空格」+ §4.16「去掉空白（引号内保留）」 · 一致。
- **R-18** 示例 `my app`my application` 的短词含空格 · 卡在 §4.17「短词：字母、数字、`-`、`_`」 · 一致。
- **R-19** 示例 10 的展示态未展开映射 · 卡在 §4.16「展示态…展开映射表」 · 一致。
- **R-20** 反向映射的长词前缀歧义 · 卡在 §4.17「长词唯一」未排除 `alpha`/`alphabet` · 一致（我说不够清晰）。
- **R-21** 嵌套 `//map` 的长词唯一是全局还是按块 · 卡在 §4.17「不同块可各自定义」+「长词唯一」 · 一致。
- **R-22** 「内层优先」与「从定义处之后生效」冲突 · 卡在 §4.17 同句 · 一致。

## 六、赋值、主语与边界

- **R-25** `->$x` 在尾随块之前，拿原值还是段输出 · 卡在 §三 `[->$变量] trailing_block*` + §4.11 段输出顺序 · 一致。
- **R-23** `.name` 字段与 dotfile 宾语冲突 · 卡在 §4.8「`.name` 是 self 字段」+ §4.3「宾语是裸词」 · 一致。
- **R-27** 顶层默认错误是否终止整个 program · 卡在 §4.10「中断管道」+ §4.15「无包围场域时中断当前语句」 · 一致。
- **I-37 / R-28** 调用绑定仍无 DSL 侧契约 · 卡在 §五.6「SVO 槽到实参的映射由动词注册对应表决定」 · 一致。
- **I-39 / R-28** §五「不做类型判断/数组实参」与 §4.4/§4.13/§4.18 冲突 · 卡在 §五.3、§五.5 vs §4.13「null/数组/非数组」 · 不一致（我判边界闭合，反证席判仍冲突）。
