# S-012 R4 失败行为表

- **状态**：`unverified`
- **决策**：[D-010](../decisions/D-010.md)
- **规范**：[04 §3](dsl/04-pipeline-errors.md)
- **里程碑**：M4

## 1. 输入

普通调用失败、`|?` 左侧可捕获失败、左侧不可捕获失败、右侧失败、`if` 条件失败、循环体失败、`fn` 体内失败、emit 无订阅方/队列满、`max_emit_bytes` 超限、`max_payload_depth` 超限、schema 不符、`max_emit_count` 超限、步数超限，各一例。

## 2. 输出

| 场景 | `ok` | `error_kind` | 说明 |
| --- | --- | --- | --- |
| 普通调用失败 | 0 | 原值 | 中止当前块 |
| `\|?` 左侧可捕获 | 1 | null | `degraded=1`，右侧值 |
| `\|?` 左侧不可捕获 | 0 | 原值 | 不执行右侧 |
| `\|?` 右侧失败 | 0 | 右值 | 诊断含两侧位置 |
| `if` 条件失败 | 0 | 原值 | 中止外层块 |
| 循环体失败 | 0 | 原值 | 不继续下一轮 |
| `fn` 体内失败 | 0 | 原值 | `fn` 调用失败，调用方 `\|?` 可消费 |
| emit 无订阅方/队列满 | 不变 | 不变 | 丢弃并记日志，继续执行 |
| `max_emit_bytes` 超限 | 0 | `limit` | 不得静默丢弃 |
| `max_payload_depth` 超限 | 0 | `limit` | emit 侧失败位置在 emit 语句 |
| emit schema 不符（内核配置） | 0 | `emit_schema` | 脚本不声明 schema，只验运行时结果 |
| `max_emit_count` 超限 | 0 | `limit` | 中止当前块 |
| 步数超限 | 0 | `limit` | 中止整个执行 |

- 块中止时，已完成的工具副作用保留；`|?` 不回滚。
- 没有块级恢复、没有错误值、没有 `try/catch`。

## 3. 失败语义

- 任何“失败后继续执行同块下一条语句”的行为 → 验收失败。
- 右侧失败后返回左侧值 → 验收失败。
- `degraded` 与实际接管次数不一致 → 验收失败。

## 4. 验收命令与阈值

- **命令**：`尚未落盘`（M4 后 `tools/check.sh m4-pipeline`）。
- **阈值**：13 行逐条断言；副作用保留 1 例；块中止后不再有工具调用（用计数工具验证）。
