# S-004 NEWLINE 终止与抑制

- **状态**：`unverified`
- **决策**：[D-004](../decisions/D-004.md)、[D-006](../decisions/D-006.md)
- **规范**：[01 §7](dsl/01-lexical.md)
- **里程碑**：M1

## 1. 输入

```
let a = 1
let b = 2

let c = (1
       + 2)

let d = a
    |> f b

if a == 1
{
    write "x" a
}
```

## 2. 输出

- `let a = 1` 与 `let b = 2` 是两条语句；空行折叠，不产生空语句。
- `(` 内换行被 N2 删除；`|>` 前的行首换行被 N5 删除，`+` 前后同理按运算符优先级继续解析。
- `if` 条件与 `{` 之间的换行被 N7 删除。
- `}` 与 `else` 之间的换行被 N6 删除。
- 注释后的换行仍然终止语句（注释不吞 LF）。

## 3. 失败语义

- 一条语句跨行但不在 N2/N4/N5 允许位置 → `syntax`。
- 同一行两条语句（`let a = 1 let b = 2`）→ `syntax`。
- 未闭合 `{`/`(`/`[` → `syntax`，位置指向开定界符。

## 4. 验收命令与阈值

- **命令**：`尚未落盘`（M1 后 `tools/check.sh m1-tokens`）。
- **阈值**：N1–N8 每条至少 1 个 token golden；注释吞行负例 2 个；0 个 golden 失败。
