## 2. 规范用语

- **必须（MUST）**：实现必须满足，否则加载失败或验收不通过。
- **不得（MUST NOT）**：出现即缺陷。
- **建议（SHOULD）**：实现可偏离，但必须在 `D-*` 或 `P-*` 记录理由。
- 文中 `[D-xxx]` 指向决策记录；`[P-xxx]` 指向未决条目；`[provisional: P-xxx]` 表示该处为 rev.1 的临时可执行文本，未拍板。
