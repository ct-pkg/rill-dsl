# S-003 数字与负号

- **状态**：`unverified`
- **决策**：[D-003](../decisions/D-003.md)
- **规范**：[01 §4](dsl/01-lexical.md)、[01 §5](dsl/01-lexical.md)
- **里程碑**：M1

## 1. 输入

```
1
3.14
1 - 2
f 1 - 2
read -1
12abc
1.
```

## 2. 输出

- `NUMBER := [0-9]+("."[0-9]+)?`，不带符号。
- `1 - 2`、`f 1 - 2` 都按二元减法解析；后者是 `(f 1) - 2`。
- `read -1` 是 `(read) - 1`：裸名 `read` 是零参调用，与 arity=1 不符，加载期报 `arity`，Hint 给出 `read (-1)`。
- `12abc` 是词法错误，不得切成 `12` + `abc`。
- `1.` 是语法错误（小数部分缺失）。

## 3. 失败语义

- `syntax`：`12abc`、`1.`、`0x10`、`1e9`、`1_000`。
- `arity`：`read -1`（零参调用与 arity=1 不符）。
- 失败位置指向数字或运算符起点。

## 4. 验收命令与阈值

- **命令**：`尚未落盘`（M1 后 `tools/check.sh m1-tokens`）。
- **阈值**：上述 7 条输入逐条 token/AST 与期望一致；负数用例必须报错而非静默接受；0 个 golden 失败。
