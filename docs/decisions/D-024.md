## 争点

P-025 问的是：值里的 `类型:值` 前缀（TypeRegistry，§五）是否进入函数签名。PH-22 收口时用的是临时口径——签名键先剥离类型前缀，于是 `file:x` 与 `text:x` 同形，撞 `E-03`（E-26）。用户裁定取 **B：签名层不识别类型前缀**，并同时定了版本标记、消费者与引号透明三项配套。

## 判据（逐条）

| # | 判据 | 证据 | 结论 |
| --- | --- | --- | --- |
| 1 | 形状比较不依赖任何注册表 | 签名由 AST 机械导出（`shape.py` 只读 AST） | 满足：比较字面原文，不查 TypeRegistry |
| 2 | 前缀差异必须能被作者表达 | 用户裁定 B | 满足：`file:x` / `text:x` 是不同形状 |
| 3 | 旧口径不得静默参与匹配 | PH-22 用的是临时剥离口径 | 满足：`shape_version` + 加载期断言 |
| 4 | 引号不改变常量槽的身份 | 现行 §4.18 与 `shape.py` 的槽位模型 | 满足：按值比较、不按节点种类 |
| 5 | 版本只影响定义侧，不污染调用语法 | 调用侧不写版本 | 满足：`shape_version` 仅进 `FnDef.shape` |

## 判决

`upheld`。P-025 取 **B**：**签名层不识别类型前缀**。

1. **常量位按 AST 里保存的字面原文比较**：`String.value`、`Bare.text`、数字的规范字符串形态。不查 TypeRegistry、不拆 `类型:值`、不改 AST 结构。
2. **前缀差异进入形状**：`file:x` 与 `text:x` 是**不同形状**，可共存于同一 `//fn`。原本判同形的两个定义现在并存；原本靠剥离前缀能精确命中的跨前缀调用，现在报 `E-04`（未声明形状）。
3. **`shape_version = 2`**：
   - 落点：`FnDef.shape` 内、**仅定义侧**、作为**第一个键**；调用侧不写版本。
   - v1 = PH-22 收口时的“剥离类型前缀”临时口径；v2 = 本条。
   - 同步要求：两侧各有一个 `SHAPE_VERSION = 2` 常量（Python 与 CT），形状键构造处引用同一常量，不得各自写字面量。
4. **必须带消费者**：loader 收集每个 `FnDef` 时断言 `shape_version` 等于当前值；不匹配报实现码 `E-LOAD-FN-SHAPE-VERSION`，防止宿主注入或合并带来的旧形状静默参与匹配。**若将来去掉消费者，本条应退回“不把版本放进 AST”**——没有消费者的版本字段是装饰，不进 AST。
5. **引号透明**：`file:x` 与 `"file:x"` 同值；`'ok'` / `"ok"` / `ok` 同值。禁止用节点种类（`String` / `Bare` / `Number`）区分常量槽——槽位比较只看值，不看承载节点。
6. **取代关系**：PH-22 的 E-26 判据（`file:x` / `text:x` 同形并报 `E-03`）**被本条取代**。PH-22 卡已收口、卡面冻结，**不得回改**卡片与收口记录；本条是唯一的现行口径。

## 生效范围

函数签名键里常量位的比较口径与版本标记。适用于 Python 与 CT 两侧的形状构造、加载期唯一性检查与调用选型。不含：类型前缀在值层的语义（§五 TypeRegistry 拆分与校验不变）、调用侧语法、golden 内容。

## 理由

前缀是不是类型，属于**值域的解释**；签名是**形状的指纹**。让签名去剥离前缀，等于让指纹层替值层做了一次类型判断，而判断依据（TypeRegistry）在形状层根本不可见——两个宿主若注册的类型集不同，同一份脚本会得到不同形状，违反 §五“两个宿主得到同一 AST”。

取字面原文比较后，形状层回到纯语法：谁写的字面不同，形状就不同。代价是同一语义的两处写法（`file:x` 与 `"file:x"`）必须仍然相等，所以配了引号透明一条；否则作者换个引号就换了一个函数。

版本字段的风险是“写了没人读”。因此本条把消费者写进判决：loader 必须断言版本，否则旧形状（剥离前缀产生的 v1 键）会在宿主注入或合并时静默参与匹配，产生“看起来同形却撞 E-03”或“看起来不同形却命中”的诡异结果。消费者一旦被删，版本字段就应随之退出 AST，避免留下无人读的字段。

## 失效条件

- `shape_version` 的消费者被移除或长期无人读 → 按 §判决 第 4 点退回“不把版本放进 AST”，本条其余条款仍有效。
- 若值层最终把 `类型:值` 定为**不是值的语法**（例如移到主语专属前缀或载体属性），常量位不再出现前缀，第 2 条的差异随之消失，本条简化为普通字面比较。
- 若跨前缀调用的 `E-04` 在实测中频繁打断既有脚本（迁移期），可考虑在 Hint 里列举同动词的近似形状；不得恢复剥离前缀。
