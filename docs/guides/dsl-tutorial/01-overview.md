# 01 定位与边界

> 状态：`unverified`；依据 `docs/spec/dsl/` `v0.1 rev.1` 与 D-013。非规范性文档，冲突时规范优先。

## 1. Rill 是什么

Rill 是给 agent 写**单次工具编排**的 DSL：模型生成一小段脚本，内核加载并在一次 `dsl_exec` 里执行；脚本调用已注册工具、串接结果、做条件与有界循环、发布事件，最后返回一个 `DslResult`。

它不是通用编程语言，也不是 agent 框架。它把「这一轮要做哪几步工具调用」写成可静态检查的文本，把跨轮状态、重试、审批、调度留在内核。

```rill
# allow: read, grep, write
let hits = read "src/main.c" |> grep "TODO"
if hits.length > 0 {
    write "todo.json" hits
}
```

## 2. 解决什么问题

| 问题 | Rill 的做法 |
| --- | --- |
| 模型直接写宿主语言（如 C）调用工具，token 贵、易夹带任意代码 | 小语法面：调用、管道、`if`、`for`、`fn`、`emit` |
| 工具参数顺序与追加位置容易写错 | 统一「显式实参 ++ 管道值 ++ 隐式 `$`」的固定顺序 |
| 工具越权调用难以审计 | `# allow:` 默认拒绝 + 三层白名单 + 策略快照 |
| 失败后模型分不清「没结果」与「被拒绝」 | 失败是控制信号，`error_kind` 分类；`degraded` 标记降级 |
| 大量文本被截断后下游误判「不存在」 | 截断元数据侧车 + 粘性传播 |

## 3. 与 agent 运行时的边界

| 归内核 | 归 DSL |
| --- | --- |
| 主循环、模型调用、上下文压缩、记忆 | 单次执行的语法与语义：加载、求值、调用、事件发布 |
| 审批、调度、工具注册与策略、订阅方注册 | `# allow:` / `# deny:` / `# emit:` 的声明与检查 |
| 重试循环、等待、跨轮状态 | 一次 `dsl_exec` 内的控制流 |
| 并行 | 无；`par` 是保留字，出现即 `not_implemented` |

机械判据只有一条：**任何需要「跨语句持久状态」或「挂起后恢复」的能力归内核**。因此审批、并行调度、重试、记忆读写都不在 DSL。

## 4. 一次执行的生命周期

```
source ──加载──▶ 词法/文法 ──▶ 静态检查（名字、作用域、header、调用图）
       ──执行──▶ 逐语句求值（工具调用同步等待）
       ──返回──▶ DslResult { ok, value_json, error_kind, error_line/col, degraded, ... }
```

- 加载期错误（`syntax`、`unknown_tool`、`arity`、`no_allow_header` 等）不执行任何工具。
- 执行期失败是附着在产生它的那次 call 上的控制信号；它中止最近的块并向外传播。
- 脚本不能嵌套调用 `dsl_exec`；没有 `await`，工具调用在语义上同步。

## 5. 值模型

值只有六类：`null`、`bool`、`number`、`string`、`json_object`、`json_array`。

- 对象与数组是值，不是引用：`let` 绑定、`for` item、`fn` 参数与返回值都按值拷贝。
- `==` 不隐式转换：跨类型比较为 `false`；对象/数组按结构化深比较。
- `+` 支持数值相加、字符串拼接（任一侧是 `string`）、数组连接；其他组合运行时 `type`。
- `.length` 只挂在数组上；对象、字符串、`null` 取 `.length` 返回 `null`。
- 截断元数据是侧车 `(payload, meta)`；工具边界只看得到 `payload`。

## 6. 明确不做

| 不做 | 替代 |
| --- | --- |
| 类型系统、类型注解 | 动态值 + 工具 schema 浅校验 |
| 模块 / `import` | 单文件脚本；复用靠 `fn` |
| `try/catch`、错误值、块级恢复 | 调用级 `\|?` 降级 |
| 并行 / `par` | 全串行；`par` 出现即加载错误 |
| 链式方法调用 | `\|>` 管道是唯一数据流语法 |
| 通用对象字面量、正则字面量 | emit payload 的受限 JSON；字符串 + `grep` |
| 递归 `fn` | 加载期调用图报环 |
| `while` | `for` + 工具级 `timeout`/`interval`，或内核重试 |
| DSL 级审批语法 | 内核审批；`ToolDef.requires_approval` 由内核声明，脚本没有审批语法 |

## 7. 术语

| 术语 | 含义 |
| --- | --- |
| 加载期 | 解析 + 静态检查；失败则不执行任何工具 |
| 执行期 | 逐语句求值；工具调用同步返回 |
| call | 一次工具或 `fn` 调用节点 |
| 失败单元 | `\|?` 左侧那一个 call 的整次求值 |
| 降级 | `\|?` 左侧可捕获失败后采用右侧值，`degraded=1` |
| 侧车 | 不进入 payload 的 `truncated` / `original_size` 元数据 |
| 策略快照 | 一次执行全程只读的 allow/deny/emit/约束集合 |
