## 3. 不过的那一条：C-8 `Opaque`

**为什么不过**：判据要求「构造不出触发条件就不记通过」。0.1.0 的值模型里
`Opaque` 只作为类型占位存在，词法/语法/求值/宿主四层都没有产生 `Opaque` 实例的
路径（没有内建函数返回它，`--fakes` 也没有注入通道，两个宿主都不产出）。
没有真实入口就无法验证透传与 truthy，因此**不记通过**，也没有挪到别的相。

**不是**「实现错了」，是「无从验证」。按既定口径，无从验证等同不过。
