## 3. 已验收：C-8 `Opaque`

0.1.1 B-1 在 `tests/opaque` 落地测试通道：`support.load_test_tools` 把
`$test-opaque` 标记解成 `Opaque` 后装进假宿主，生产 `src/rill` 零改动。
断言四项：透传同一性（`log[1]["object"] is log[0]["value"]`）、truthy
（`if $h` 走真分支）、边界不有损（`jsonable` 原样返回且不可 JSON 序列化）、
反向隔离（生产 `--fakes` 对标记惰性、`src/rill` 不引用通道）。
无通道时该测试在副本上红，落地后绿；证据与门禁原文见
`docs/reviews/opaque-c8-evidence.md`。

**2026-11-16 追记**：Python 参考实现退场后，上述证据通道不可复跑；C-8 按
PH-23 卡 §10 改记为“证据归档、不可复跑”，移植见 `issues/RILL-001.md` 与
`docs/planning/rill-0.1.1-backlog.md` 的 `BL-003`。2026-11-15 的 GO 与
`v0.22.0` 不变。
