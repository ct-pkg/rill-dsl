## 3. 判定为「不比较」而非「放过」的字段

这些字段两侧必然不同或与实现无关，**从等值比较中剔除但保留在输出里**，不是差异：

| 字段 | 原因 | 出处 |
| --- | --- | --- |
| AST `span` | 既有 golden 口径本来就不含 span；parser 未携带精确行列 | PH-14 |
| `host_meta.tool_meta.transport.pid` | 两侧是不同进程，进程号必然不同 | PH-20 §5 |
| 绝对路径 | fixture 在各自临时目录里跑，路径前缀不同 | PH-19 |

## 4. 已知行为差异（1 条，已结案，不是本相新差异）

**非 ASCII 词边界**：`str.isalnum()` 与 CT 的字节判定在 `a —b` 这类输入上不同。
Python 会把两个 `BARE` 并成一个 token，违反规范 §4.16「压缩→展示保持 token 序列」；
CT 保留空格。判据锚点：§4.16 与 §1「符号即边界」，探针 `a —b`。
**结论：CT 正确，Python 侧是候选缺陷；不改参考实现（冻结），登记为已知偏差。**

详见 `docs/reviews/diff/PH-19.md` §10。
