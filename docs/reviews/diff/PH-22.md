## 3. PD-1 / PD-2（`expected_diff`）

- 口径：`Token.raw_len` 由 lexer 一次算好；`p_adjacent` 与 `f_raw_width` 只读它。
- PD-1 `$"-x"`：两侧解析一致，`testdata/0.1.0/directed/pd1` 在 ast/error/eval 三层 0 差异。
- PD-2 `"n="$v`：CT 按 §4.16 解析成功；Python 参考实现冻结，仍报 `E-PARSE-UNEXPECTED@2:12`。
  该差异登记在 `testdata/0.1.0/directed/pd2/case.json#expected_diff`，`diff.py` 按
  “用例 + 层 + 两侧摘要”精确匹配；摘要不符即按普通差异失败，无通配豁免。
