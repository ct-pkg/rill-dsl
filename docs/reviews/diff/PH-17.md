## 3. 覆盖到的语义点

| 判据 | 用例 | 观察点 |
| --- | --- | --- |
| E-2 truthy 与 `ok` 不混 | `control/if-subject` | `contains` 返回 `true` → 走 then 分支 `break "on"`；条件不是 `[ok]` |
| E-3 each 三态 | `control/each-value`、`each-round-failure` | 数组逐项；失败轮占 `null` 并继续；失败位由 each 级收口为 `ok=false` |
| E-3 each 级 `[error]` | `control/each-level-error` | `$` 是首个失败轮的规范串，块输出接回 each 结果 |
| E-4 break 场域 | `control/break-pipe` | 管道段 `[error]` 内 break 只中断管道，program 以 `"halt"` 收口 |
| E-4 顶层 break | `control/pipe-segment-error` | 末条 `break $last` 被 program 层截住，值为 `{"format":"yaml"}` |
| E-5 分支三态与顺序 | `parallel/three-state` | 成功 / break 失败 / 未处理失败 / 已处理失败，值数组与首个错误按源序 |
| E-5 `[results]` | `parallel/results-array` | 块 `$` = 结果数组，块输出覆盖 parallel 的值 |
| E-6 函数 | `call/defaults`、`call/return-last` | 参数去重、默认值只在缺实参时求值、返回最后一条语句段输出 |
| E-1 管道只传 value | `control/pipe-three`、`pipe-segment-error` | 上游失败不回溯；本段 `[error]` 处理后下游照常收到值 |

## 5. 本层之外（未计入通过）

- `Bytes` / `Opaque`：无 fake 注入通道，仍无单测（沿用 PH-16 E-5 的未通过口径）。
- 真实并发调度、取消、超时：本层按源序串行模拟，接口留并发位。
- 真实宿主能力（PH-19/PH-20）与格式化（PH-18）。
- trace / log 轨迹：CT `run` 信封不输出，diff 只比 `ok/value/error/host_meta`。
- `break` 值不是字符串时：Python 会把该值当错误串，本层只支持字符串（`break_error`）。
