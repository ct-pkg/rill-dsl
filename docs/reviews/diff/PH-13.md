## 4. 协议与退出码（E-5）

```console
$ ./ct/bin/rill_ct tokenize testdata/0.1.0/positive/tokens/compact/source.rill
{"tokens":[{"kind":"VERB","text":"read","line":1,"col":1}, ...]}
$ echo $?
0

$ ./ct/bin/rill_ct tokenize testdata/0.1.0/negative/tokenize/map-unclosed/source.rill
{"error":{"stage":"tokenize","code":"E-LEX-MAP-UNCLOSED","line":1,"col":1,"message":"//map 区块未闭合：缺少 }"}}
$ echo $?
2
```

成功信封顶层键为 `tokens`，诊断信封顶层键为 `error`；与 Python 版同形。用法错误走
`cli/E_USAGE`（与 Python 版相同），不属于本卡的词法判据。

规范 CR / golden 修订）。
