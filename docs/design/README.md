## 2. 为什么不直接搬走

- v0.1 是用户提供的原文，拆分或改写会破坏“原文保留”的前提；移动也不能把它变成已定稿的规格。
- 讨论稿是单一问题清单，拆开会产生重复与断链；定稿时再按主题迁入 `docs/spec/` 与 `docs/decisions/`。
- 保留原位同时保留了历史提交锚点，D-001 与 PENDING 的引用仍可追溯。

这是对四层模型的一次显式归类：**历史输入留在实现记录层，但声明它不属于规范正文**；没有把它伪装成主张层或规格层。
