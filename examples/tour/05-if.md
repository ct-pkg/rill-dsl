# 05 `if` / `else-if` / `else`

**演示什么**：条件就是 `expr`（值、动词调用或管道）；`if` 本身不产生值，动作全在块里。

**语法要点**

- `if <expr> { ... }`，可接任意个 `else-if <expr> { ... }`，最后可接 `else { ... }`。
- `if` 后面的第一个 `{` 永远是 body，条件不挂尾随块。
- truthy / falsy 按值判定：`null`、`false`、`0`、`""`、`[]`、`{}` 为假，其余为真。
  注意 `[]`/`{}` 在 RILL 里是 **falsy**（和 JavaScript 相反）。
- `if` 不参与管道，也是语句而不是表达式，所以整段 `if` 的段输出是进入时的 `$`。

**运行**（在 `examples/tour/` 下）

```console
$ ../../ct/bin/rill_ct run 05-if.rill
```

**真实输出**

```console
空文件 falsy，非空文件 truthy
{"ok":true,"value":null,"error":null,"host_meta":{},"host":{"profile":"shell","principal":{"kind":"os-user","name":"samxx"}}}
```

退出码 `0`。`data/empty.txt` 是 0 字节，`<read>` 得到 `""` → falsy，第一个分支不进入；
`data/greeting.txt` 非空 → truthy，走 `else-if`。`value` 是 `null`：`if` 只做判断，
不产出值。
