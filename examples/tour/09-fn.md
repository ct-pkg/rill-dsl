# 09 `//fn{}` 定义与 `@` 调用

**演示什么**：`//fn{}` 里定义**没有名字**的函数，正文用同形的 `@ <动词> 值...` 调用。
函数靠“形状键”被选中：动词、位身份、常量值、状语名集合、介词名与顺序；参数变量名、
默认值、状语值不进签名（D-022）。

**语法要点**

- `//fn{}` 是脚本头部区块，只能放在语句之前；`@` 后直接写 `verb_call`。
- 旧形态（`@` 后跟字符串名字）一律解析期 `E-07`，没有回退到名字查找的路径。
- 调用形状与定义形状**精确相等**才选中；不做最近匹配、不做优先级。
- 模板第一段的参数位在调用里都要写值；同一参数在模板多处出现时，各次值必须相等，
  否则运行期 `E-06`。
- `$变量?默认值` 只允许出现在尾部；带默认值的介宾可整段省略。中间跳写是加载期
  `E-LOAD-FN-DEFAULT-NOT-TAIL`，缺必需位是 `E-LOAD-FN-ARITY`。
- 同一 `//fn{}` 内两个定义同形是加载期 `E-03`；调用无候选 `E-04`；多候选 `E-05`。
- 函数体最后一条语句的段输出即返回值；空体返回 `null`。

**运行**（在 `examples/tour/` 下）

```console
$ ../../ct/bin/rill run 09-fn.ri
```

**真实输出**

```console
RILL
hello
A
B
{"ok":true,"value":"B","error":null,"host_meta":{},"host":{"profile":"shell","principal":{"kind":"os-user","name":"samxx"}}}
```

退出码 `0`。前两行是第一个函数：`'RILL'` 写宾语位、`[to] user` 写介宾位；第二次调用
省略可选介宾，`$who` 取默认值 `user`。后两行是第二个函数：主语 `A` 与宾语 `B` 分别
绑到 `$left` / `$right`。程序最终 `value` 是最后一次调用的返回值。
