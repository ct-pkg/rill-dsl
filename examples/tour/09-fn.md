# 09 `//fn{}` 定义与 `@` 调用

**演示什么**：`//fn{}` 里定义具名函数，正文用 `@ "名字" 实参...` 调用；实参按位置
绑定到模板里的 `$变量`，尾部参数可写默认值，函数返回最后一条语句的段输出。

**语法要点**

- `//fn{}` 是脚本头部区块，只能放在语句之前；正文出现定义形状是解析期
  `E-PARSE-FN-DEF-BODY`。
- 模板是 `verb_call`（可带 `|>`），参数位 = 模板里 `$变量` 按首次出现去重后的顺序。
- `$变量?默认值` 只允许出现在尾部；中间跳写是加载期 `E-LOAD-FN-DEFAULT-NOT-TAIL`。
- 调用名按字符串精确匹配（大小写敏感），实参个数不符是加载期 `E-LOAD-FN-ARITY`。
- 函数体最后一条语句的段输出即返回值；空体返回 `null`。
- 模板里只有一个主语槽：多参数要把变量放在不同成分位（如主语 + 宾语）。

**运行**（在 `examples/tour/` 下）

```console
$ ../../ct/bin/rill run 09-fn.rill
```

**真实输出**

```console
RILL
world
L
right-default
{"ok":true,"value":"right-default","error":null,"host_meta":{},"host":{"profile":"shell","principal":{"kind":"os-user","name":"samxx"}}}
```

退出码 `0`。前两行是 `announce` 的两次调用：`'RILL'` 绑到 `$who`，省略实参时用默认值
`world`。后两行是 `pick`：只传一个实参 `'L'` 时，`$right` 取默认值 `right-default`。
程序最终 `value` 是最后一次调用的返回值——函数体最后一条 `<send>` 的段输出。
